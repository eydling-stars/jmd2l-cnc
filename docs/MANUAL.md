# 1. О продукте

Панель управления — это комплект из трёх частей: платы управления на Arduino,
двух драйверов шаговых двигателей и программы-панели, которая запускается в
браузере на обычном компьютере.

Программа управляет столом фрезерно-сверлильного станка JET JMD-2L по двум
осям — **X** (поперечная) и **Y** (продольная). Оператор видит состояние станка
на экране и двигает стол кнопками или стрелками клавиатуры.

Главная особенность — **защита от закусывания фрезы**. Программа измеряет
обороты шпинделя и ток его привода и останавливает стол, если фреза застряла в
материале. Стол при этом не едет, а двигатели удерживаются, чтобы застрявшая
фреза не тянула привод дальше.

## 1.1. Что система делает

- двигает стол по осям X и Y: джог (удержание кнопки) и ход на заданное
  расстояние;
- следит за концевиками и не даёт оси уйти за них;
- следит за оборотами шпинделя и током привода, останавливает стол при
  закусывании;
- показывает состояние станка, настройки и журнал событий;
- проверяет себя автотестами без подключённых двигателей.

## 1.2. Чего система не делает

- **не управляет шпинделем.** Оператор включает и выключает его штатными
  кнопками станка. Система только измеряет обороты и ток;
- **нет домашнего положения.** Система не знает, где «край стола», поэтому не
  может ни привести стол в исходное положение, ни обнулить его самостоятельно.
  Всё движение — только по команде оператора;
- **нет оси Z** — привода высоты нет;
- **нет G-кодов и траекторий** — только ручное управление;
- **нет записи на карту памяти** и отдельной программы: панель работает в
  браузере.

## 1.3. Кому адресовано

Инструкция рассчитана на оператора станка и на наладчика, который подключает
комплект. Первые главы нужны при монтаже, остальные — при ежедневной работе.

## 3.1. Почему так

- **Node.js 12.22.12** — последняя версия, официально работающая на Windows 7.
  Она входит в установку, отдельно ставить не нужно;
- **serialport 10.0.0** — версия последовательного порта, которая работает на
  Node.js 12. Более новые версии требуют Node.js 14, а он на Windows 7
  официально не поддерживается;
- **Arduino IDE не нужен** — прошивку собирает и заливает комплектный скрипт,
  раздел 7.3. Если скрипт по какой-то причине не подошёл, ставьте **Arduino
  IDE 1.8.19**: IDE 2.x на Windows 7 не работает, на Windows 10 и 11 подойдёт
  любая версия.

## 3.2. Важно про безопасность

Windows 7 больше не получает обновлений безопасности. Панель работает только
на `localhost` и не выходит в сеть сама, но браузер на этой машине уязвим.
**Не открывайте панель в интернет и не выпускайте компьютер станка в сеть** без
свежего браузера.

# 4. Установка программы

## 4.1. Что нужно

Папка с комплектом установки. В ней обязательно есть:

```
install\install.cmd
install\payload\node-v12.22.12-win-x64.zip
install\payload\arduino\arduino-cli.exe
```

Первые два нужны, чтобы программа вообще поставилась, третий — чтобы плату
можно было прошить. Без него установка пройдёт, но прошить плату будет нечем,
и тогда понадобится Arduino IDE.

Если чего-то из этого нет, комплект собран не полностью. Выполните на
машине с интернетом:

```
powershell -ExecutionPolicy Bypass -File install\fetch-node.ps1
powershell -ExecutionPolicy Bypass -File install\fetch-arduino.ps1
```

Первый скрипт скачает Node.js с официального сервера и сверит контрольную
сумму, второй возьмёт инструменты прошивки из установленной Arduino IDE и сам
проверит, что прошивка собирается без интернета.

Установленная программа занимает около 386 МБ, если в комплекте были
инструменты прошивки: 50 МБ — Node.js, 333 МБ — инструменты прошивки, остальное —
панель и руководство. Из клона GitHub инструментов прошивки нет, и размер
получается около 53 МБ: прошить плату тогда можно, поставив Arduino IDE,
раздел 7.2.

## 4.2. Установка

1. Скопируйте папку комплекта на компьютер станка. Не запускайте установщик
   прямо из архива или с сетевого диска — распакуйте на диск целиком.
2. Двойным щелчком запустите `install\install.cmd`.
3. Согласитесь на запрос прав администратора — без них нельзя создать ярлыки
   и запись в «Программы и компоненты».
4. Дождитесь сообщения **«Готово»**.

Установщик сам:

- проверит версию Windows и откажется ставить на Vista и старше;
- сверит контрольную сумму Node.js;
- скопирует программу, прошивку, документацию и зависимости сервера;
- распакует Node.js внутрь своей папки — **системный PATH не меняется**;
- создаст ярлык на рабочем столе, в меню «Пуск» и в папке программ;
- запишет запись в «Программы и компоненты».

## 4.3. Куда ставится

По умолчанию:

- 64-разрядная Windows — `C:\Program Files\JMD-2L CNC`
- 32-разрядная Windows — `C:\Program Files (x86)\JMD-2L CNC`

Свою папку можно задать параметром:

```
powershell -ExecutionPolicy Bypass -File install\install.ps1 -InstallDir "D:\CNC"
```

## 4.4. Тихая установка

```
powershell -ExecutionPolicy Bypass -File install\install.ps1 -Unattended -NoShortcuts
```

Подходит для развёртывания по сети. Ключи: `-Unattended` (без вопросов),
`-NoShortcuts` (без ярлыков), `-Force` (переустановить поверх без вопроса).

## 4.5. Запуск

Ярлык **JMD-2L CNC** на рабочем столе либо файл `StartPanel.cmd` в папке
программы. Через несколько секунд откроется панель:

```
http://localhost:8080
```

Если панель не открылась сама — откройте этот адрес в браузере вручную.

## 4.6. Если панель не открывается

| Симптом | Причина | Что делать |
|---|---|---|
| Окно «Server stopped» | сервер упал или порт занят | закройте вторую копию панели, запустите снова |
| Панель открылась, платы нет | плата не подключена или нет драйвера | проверьте USB и раздел 7.6 |
| Панель открылась, «COM-портов не найдено» | плата не вставлена | вставьте плату, подождите 2 секунды — поиск повторится сам |

# 5. Подключение к станку

Подключение делают при снятом питании. Порядок: сначала земля, потом питание,
потом сигналы.

## 5.1. Распиновка платы

| Пин | Порт МК | Куда идёт |
|---|---|---|
| D9 | PB1 | PUL — импульсы шагов оси X |
| D8 | PB0 | DIR — направление оси X |
| D7 | PD7 | ENA — включение оси X |
| D6 | PD6 | PUL — импульсы шагов оси Y |
| D5 | PD5 | DIR — направление оси Y |
| D11 | PB3 | ENA — включение оси Y |
| D2 | PD2 (INT0) | тахометр шпинделя |
| D3 | PD3 | концевик X-1 |
| D4 | PD4 | концевик X-2 |
| D10 | PB2 | концевик Y-1 |
| D12 | PB4 | концевик Y-2 |
| D13 | PB5 | реле |
| A0 | PC0 | датчик тока ACS712 |
| GND | — | общая земля со всеми устройствами |
| 5V | — | питание датчиков |

## 5.2. Важные требования к проводке

**Общая земля.** Земля Arduino, обоих драйверов, датчика тока и тахометра должна
быть одной точкой. Отдельная земля на плате питания привода без перемычки на
Arduino приведёт к тому, что порт не откроется или данные будут битыми.

**Подтяжки встроенные, внешние резисторы НЕ нужны.** Все пять входов (D2, D3,
D4, D10, D12) прошивка включает как `INPUT_PULLUP`: в покое пин держится на
+5 В, выключатель заземляет его.

> Старая редакция руководства требовала внешние подтяжки 4,7 кОм на каждый вход
> и объясняла это тем, что генерация шагов затирает подтяжки. **Объяснение было
> неверным.** Проверено по коду: после `setup()` порты пишутся только как
> `PORTB ^= бит` и `PORTD ^= бит` в прерывании — это чтение-изменение-запись.
> AVR читает в `PORTx` содержимое защёлки, а для входного пина бит защёлки и
> есть включение подтяжки, поэтому он возвращается на место. Гасит подтяжку
> только запись в `DDRx` или явное обнуление бита в `PORTx` — ни того, ни
> другого после `setup()` в коде нет.
>
> Если длинные провода начнут ловить наводки, добавьте внешний резистор
> 4,7 кОм **параллельно** встроенному: две подтяжки дают ту же логику, настройки
> менять не нужно.

**Экранирование и витая пара.** Датчики лучше тянуть витой парой или
экранированным проводом, экран заземлять **только со стороны платы**, чтобы
наводки не шли поперёк сигнала.

**Разнесение.** Кабель шаговых сигналов (D9, D8, D7, D6, D5, D11) держите
отдельно от проводов питания двигателей.

## 5.4. Концевик: полный пример на X-1

Разберём целиком одно подключение — концевик X-1 на D3. Остальные три
подключаются так же, меняется только пин.

**Что нужно:** микровыключатель KW1-103-6 с тремя выводами — общий, нормально
замкнутый и нормально разомкнутый. В схеме участвуют два из трёх.

**Подключение по умолчанию:**

```
        +5 В (пин Arduino)
          │
          └── встроенная подтяжка (в прошивке, отдельный резистор не нужен)

   D3 ────┬──────────── контакт «нормально РАЗОМКНУТЫЙ» выключателя
   (PD3)  │                              │
          │                              ├── GND (пин Arduino)
          │                              │
          └── GND платы  ← общая земля со всеми модулями

   Рычаг не нажат:  D3 = +5 В (HIGH)  →  концевик НЕ нажат
   Рычаг нажат:     D3 = 0 В (LOW)    →  концевик НАЖАТ
```

| Вывод выключателя | Куда |
|---|---|
| нормально разомкнутый (NO) | D3 |
| общий (COM) | GND |
| нормально замкнутый (NC) | не подключать |

**Как отличить выводы, не веря надписям.** Номера на корпусе KW1-103-6 у разных
производителей не совпадают, поэтому проверьте тестером при свободном рычаге:

1. Общий вывод (COM) — тот, который звонится **с обоими** остальными.
2. Из двух оставшихся тот, что звонится с COM при не нажатом рычаге, —
   нормально замкнутый (NC). Второй — нормально разомкнутый (NO).
3. Нажать рычаг: NC отключится, NO включится.

Подключайте только после этой проверки. Если перепутать NO и NC, концевик
работает наоборот: остановка сработает не с той стороны.

**Проверка после подключения** (вкладка «Пусконаладка», шаг 3): в карточке оси X
загорается «X-1» при нажатии и гаснет при отпускании. Если наоборот — переставьте
NO и NC и поставьте полярность «нажатие даёт HIGH», либо оставьте как есть и
прочитайте 5.5.

## 5.5. Концевик: вариант с нормально замкнутым контактом

Вариант из 5.4 не замечает **обрыв провода**: при обрыве пин D3 всплывает к
+5 В, и плата считает концевик не нажатым. Провод может перетёрться, а система
об этом не узнает.

Если обрыв должен приводить к остановке, соберите наоборот, на нормально
замкнутом контакте:

```
   D3 ────── контакт «нормально ЗАМКНУТЫЙ» выключателя ── GND
             (то есть NC на D3, COM на GND)

   Рычаг не нажат:    D3 = 0 В (LOW)   →  концевик НЕ нажат
   Рычаг нажат:       NC разомкнулся, D3 всплывает к +5 В (HIGH) → НАЖАТ
   Провод перетёрся:  то же, что при нажатии — ось остановится
```

Такой вариант требует одной настройки: **«Полярность концевиков» = «нажатие даёт
HIGH»** (настройка 13). Без неё плата будет считать концевик нажатым всё время
и ход закроется совсем.

Выбор между вариантами — за оператором. По умолчанию стоит вариант из 5.4.

## 5.6. Драйверы DM542

```
Arduino D9  ──► DM542 (ось X) PUL+        Блок питания 24 В ──► DM542 V+ V−
Arduino D8  ──► DM542 (ось X) DIR+        DM542 A+ A-  ──► 57HS76 (ось X)
Arduino D7  ──► DM542 (ось X) ENA+
Arduino GND ──┬─► DM542 (ось X) PUL−     DM542 GND
              ├─► DM542 (ось X) DIR−
              └─► DM542 (ось X) ENA−

Arduino D6  ──► DM542 (ось Y) PUL+        Блок питания 24 В ──► DM542 V+ V−
Arduino D5  ──► DM542 (ось Y) DIR+        DM542 A+ A-  ──► 57HS76 (ось Y)
Arduino D11 ──► DM542 (ось Y) ENA+
Arduino GND ──┬─► DM542 (ось Y) PUL−     DM542 GND
              ├─► DM542 (ось Y) DIR−
              └─► DM542 (ось Y) ENA−
```

Схема общая анодная: сигнал идёт на «+» каждого входа, все три «−» — на общую
землю. «−» соединяются между собой и с GND платы — либо перемычкой «общая
земля» на самом драйвере, либо отдельными проводами, как показано выше
(сверьтесь с руководством на ваш экземпляр DM542: вариант зависит от партии).

**ENA активен по LOW** — проверено на стенде: при HIGH мотор стоял, хотя ENA в
панели показывался включённым. Не меняйте полярность ENA (настройки 24 и 29) на
обратную без проверки на стенде.

## 5.7. Датчик тока ACS712

```
Arduino 5V  ──► ACS712 VCC
Arduino GND ──► ACS712 GND
Arduino A0  ──► ACS712 OUT
```

Датчик включается в разрыв провода, по которому идёт ток главного привода
шпинделя — обычно один из проводов клеммы блока питания. Полярность важна:
при обратной уставка тока уходит в минус и защита не сработает.

Ноль датчика (настройка 6) выставляется калибровкой при выключенном шпинделе —
см. раздел 8. Чувствительность (настройка 7) для ACS712-20A равна 100 мВ на А.

## 5.8. Тахометр

Щелевой фототранзистор ставится напротив диска с прорезями на валу шпинделя.
Свет проходит, когда резина **в прорези**; число прорезей задаёт настройка 3
(обычно 100).

```
Arduino 5V  ──► коллектор фототранзистора ... D2
Arduino GND ──► эмиттер фототранзистора
```

D2 — единственный вход, где внешняя подтяжка 4,7–10 кОм на +5 В заметно
полезна: встроенной (около 20–50 кОм) при быстром вращении и длинном проводе
не хватает. Настройки при этом не меняются, добавляется только устойчивость.
Если счётчик оборотов скачет — это первое, что стоит устранить.

## 5.9. Реле

```
Arduino D13 ──► IN   модуля реле KY-019
Arduino 5V  ──► VCC модуля реле
Arduino GND ──► GND модуля реле
```

Реле **активно по LOW**. Сухой контакт (COM, NO, NC) включается в цепь по
усмотрению оператора — назначение задаёт не система. Режим (выключено / импульс
/ удержание) задают настройки 11 и 12.

# 6. Настройка драйверов DM542

Перемычки ставятся **при снятом питании**, на обоих драйверах одинаково.

| Перемычка | Положение | Что означает |
|---|---|---|
| SW1 | OFF | ток 2.4 А |
| SW2 | ON | ток 2.4 А |
| SW3 | OFF | ток 2.4 А |
| SW4 | OFF | |
| SW5 | OFF | 400 шагов/оборот |
| SW6 | OFF | 400 шагов/оборот |
| SW7 | ON | 400 шагов/оборот |
| SW8 | ON | 400 шагов/оборот |

Итого: **SW1/2/3 = OFF/ON/OFF**, **SW4 = OFF**, **SW5…SW8 = OFF/OFF/ON/ON**.

## 6.1. Проверка после монтажа

В поле выбора микрошага DM542 есть пресет «1/10 оборота». Проверьте его на
холостом ходу до установки привода: вал должен повернуться **ровно на 36°**.
Отклонение больше 2° означает, что перемычки собраны неверно.

# 7. Прошивка платы

Прошивку выполняют один раз — при монтаже и после замены Arduino. Плата уже
прошита, если комплект собран на месте.

## 7.1. Драйвер USB

Плата Arduino Nano видна в Windows как **CH340**. Драйвер ставится один раз.

| Система | Что делать |
|---|---|
| Windows 10, 11 | драйвер встроен, ничего делать не нужно |
| Windows 7, 8.1 | установить драйвер CH340 с сайта WCH |

На Windows 7 перед установкой драйвера поставьте обновления KB4474419 и
KB4490628 — без них подпись драйвера не проверяется и он не встаёт.

## 7.2. Инструменты

Отдельно ничего ставить не нужно: в установленную папку входит всё, чем
компилируется и заливается плата.

| Что лежит в папке `arduino` | Размер | Зачем |
|---|---|---|
| `arduino-cli.exe` | 36 МБ | собирает `.ino` в `.hex` |
| `data\packages\arduino\tools\avr-gcc` | 209 МБ | компилятор ATmega |
| `data\packages\arduino\hardware\avr` | 2,6 МБ | ядро платы и список плат |
| `data\packages\arduino\tools\avrdude` | 6,7 МБ | записывает `.hex` в плату |

Скрипт `bench\flash.ps1` находит эти файлы сам. Ни интернет, ни Arduino IDE
при прошивке не нужны.

Если папки `arduino` рядом с программой нет, комплект был собран без
инструментов прошивки — так бывает, если программа поставлена из клона
GitHub, а установщик не нашёл комплект. Тогда поставьте **Arduino IDE 1.8.19** —
на Windows 7 версия 2.x не запускается. IDE нужна только ради `avrdude`: скрипт
`bench\flash.ps1` найдёт его сам, а собирать прошивку даже не придётся:

```
powershell -ExecutionPolicy Bypass -File bench\flash.ps1 -Port COM4 -SkipBuild -BuildPath firmware\prebuilt
```

Готовый `.hex` лежит в `firmware\prebuilt`. Всё то же самое можно сделать
руками через IDE, раздел 7.5.

## 7.3. Прошивка скриптом

1. Вставьте плату в USB. Узнайте номер порта: «Диспетчер устройств» →
   «Порты (COM и LPT)». У нас это обычно COM4.
2. **Закройте панель.** Она держит COM-порт занятым, и прошивка не пойдёт.
3. Откройте командную строку и выполните, подставив свой порт:

```
cd /d "%ProgramFiles%\JMD-2L CNC"
powershell -ExecutionPolicy Bypass -File bench\flash.ps1 -Port COM4
```

Скрипт сам соберёт прошивку из `firmware\jmd2l_cnc\jmd2l_cnc.ino`, сам
переведёт плату в режим загрузчика и сам зальёт. Нажимать RESET руками не
нужно — скрипт делает это сам, в отличие от Arduino IDE.

**Признак успеха одна** — строка `N bytes of flash verified` в выводе. Код
возврата у `avrdude` на этой плате равен 1 даже при успешной записи, поэтому
ориентироваться надо на эту строку, а не на код.

Собрать прошивку, не заливая плату, — добавьте ключ `-SkipBuild` и укажите
папку с готовым `.hex` ключом `-BuildPath`.

Промежуточные файлы сборки скрипт кладёт во временную папку, а не в папку
программы: та лежит в Program Files и обычному пользователю не принадлежит.

## 7.4. Если загрузка не идёт: ручной сброс

Раздел про Arduino IDE. **Через скрипт из 7.3 это не бывает** — сброс там
делается автоматически.

**На этой плате ручной сброс — это ожидаемо, а не поломка.** У нашей платы
CH340 не выполняет автоматический сброс: после нажатия «Загрузить» Arduino IDE
сообщает `programmer is not responding`. Лечится вручную:

1. Нажмите «Загрузить».
2. **Когда внизу появится надпись `Connecting...` или `Отправка`** — быстро
   нажмите кнопку **RESET** на плате и отпустите.
3. Загрузка пойдёт обычным порядком.

Кнопку RESET нажимают именно в момент `Connecting...`: позже — уже поздно,
раньше — плата не успела войти в загрузчик.

Если надпись `Connecting...` проскочила быстро и вы не успели — повторите,
загрузка безопасна, плату можно начинать заново сколько угодно раз.

## 7.5. Прошивка через Arduino IDE

Способ запасной, для случая когда в папке программы нет `arduino`.

1. Откройте Arduino IDE.
2. «Файл» → «Открыть» → папка `firmware\jmd2l_cnc` из комплекта. В ней лежит
   `jmd2l_cnc.ino` — это и есть программа платы.
3. «Инструменты» → «Плата» → **Arduino Nano**.
4. «Инструменты» → «Процессор» → **ATmega328P (Old Bootloader)**, если плата
   Nano v3.0 старого образца; иначе ATmega328P.
5. «Инструменты» → «Порт» → ваш COM.
6. Нажмите **«Скетч» → «Загрузить»**.

Если плата не даёт залить себя с первого раза — нажимайте RESET по 7.4.

После успешной загрузки в окне монитора порта должна появиться строка:

```
JMD-2L CNC 2.0 ready
```

## 7.6. Плата не видна

| Симптом | Причина | Что делать |
|---|---|---|
| В списке портов нет нового | не установлен драйвер CH340 | раздел 7.1 |
| Порт есть, но не открывается | порт занят другой программой | закройте панель и другие терминалы, переподключите плату |
| `programmer is not responding` | не сработал автосброс | раздел 7.4, нажать RESET при `Connecting...` |
| Плата молчит, баннера нет | RTS держит ATmega в загрузчике | выключите питание и воткните плату заново |
| Баннер есть, панель молчит | занят COM-порт | проверьте, не открыт ли порт в другом окне |

# 8. Первый запуск

После установки откройте панель и вкладку **«Пусконаладка»**. Это мастер из
семи шагов: ток, тахометр, концевики, шаги на миллиметр, направление осей,
реле, защита.

| № | Шаг | Что проверяет |
|---|---|---|
| 1 | Ток двигателей | ток холостого хода и под нагрузкой |
| 2 | Тахометр | счёт импульсов и обороты |
| 3 | Концевики | полярность и правильность подключения |
| 4 | Шаги на мм | соответствие хода эталону |
| 5 | Направление осей | соответствие стрелки и движения |
| 6 | Реле | срабатывание по аварии |
| 7 | Защита от закусывания | срабатывание по оборотам и току |

Каждый шаг выполняет команды платы и проверяет результат. Отметки о выполнении
хранятся в браузере. Порядок выбран так, чтобы неисправная полярность
концевиков не заблокировала пусконаладку: концевики проверяются **до** первого
хода, потому что при неверной полярности висящие входы читаются нажатыми и
путь закрывается.

Шаг **4 «Шаги на мм»** — самый важный для точности. Подробности в главе 10.

# 9. Настройки уставок

Вкладка **«Настройки»**. Изменения сохраняются кнопкой **«Сохранить в
плату»**. Пока не нажата, значения живут только в памяти платы и пропадают при
её перезагрузке.

## 9.1. Что обязательно выставить до работы

| Параметр | Где | Почему важно |
|---|---|---|
| Шаги на миллиметр, ось X | Пусконаладка, шаг 4 | иначе ход «на 100 мм» пройдёт не 100 мм |
| Шаги на миллиметр, ось Y | Пусконаладка, шаг 4 | то же |
| Полярность концевиков | Пусконаладка, шаг 3 | иначе система считает их нажатыми |
| Направление осей | Пусконаладка, шаг 5 | иначе стрелка «вправо» поедет влево |
| Ток двигателей | Защита, «ток выше» | ложные срабатывания или сгоревший двигатель |
| Порог взвода защиты | Защита | слишком высокий — защита не взведётся |

## 9.2. Скорости хода

Три пресета — «Точная», «Рабочая», «Быстрая» — задаются в оборотах двигателя
в минуту. Скорость на ползунке и длина хода («ход, мм») панель записывает в
плату сама, с задержкой в 1,2 секунды после последнего изменения: ползунок
шлёт команду на каждое движение, а ресурс ячейки памяти платы около 100 тысяч
циклов записи.

Кнопка **«Применить»** в карточке «Безопасности» эти слоты не трогает — только
свои уставки.

## 9.3. Правило: ход, мм — держите небольшим

Если «шаги на миллиметр» выставлены неверно, команда «ход 100 мм» уедет
не туда. До первой проверки по эталону не задавайте ход больше 10 мм.

# 10. Шаги на миллиметр — как правильно выставить

Это единственная настройка, от которой зависит точность всех ходов.

## 10.1. Что означает

«Шаги на миллиметр» — сколько шагов двигателя приходится на 1 мм хода
винта. Если двигатель делает 400 шагов на оборот, а винт идёт с шагом 2 мм на
оборот, то на миллиметр приходится 200 шагов.

## 10.2. Как измерить

1. Установите «ход, мм» равным **10**.
2. Задайте скорость «Рабочая».
3. Обнулите ось: вкладка «Управление» → ось → «Обнулить».
4. Запустите ход на 10 мм в любую сторону, дождитесь конца.
5. Измерьте, насколько стол сдвинулся: `h` мм.
6. Новые шаги на миллиметр = старые × 10 ÷ h.

Пример: стояло 200, фактически стол сдвинулся на 9,5 мм → 200 × 10 ÷ 9,5 = **210**.

## 10.3. Как это хранится

Плата хранит не «шагов на миллиметр», а **микрометров на оборот** двигателя
(по умолчанию 100 000, то есть 100 мм на оборот). Панель переводит это в
шаги на миллиметр по формуле `шагов на оборот ÷ мкм на оборот`. Поэтому если в
настройках видно значение около 400 при ходовом винте 2 мм — это опечатка
настройки, а не неисправность панели.

> Типичная ошибка — записать в это поле 400, взяв это из паспорта двигателя.
> Тогда панель покажет 1 мкм на шаг, и стол будет ползти в сотни раз
> медленнее заданного.

## 10.4. Если стол едет медленнее, чем задано

Проверьте по журналу: при ходе плата пишет фактическое число шагов в секунду.
Сравните его с ожидаемым. Если фактическое заметно меньше, а положение верное,
— причина в частоте шагов на пределе (20 000 шаг/с) или в том, что ход
задан слишком быстро для рампа.

Если же фактическая частота примерно **вдвое** ниже заданной (в журнале `hz`
9913 шаг/с, фактически 4100–4600) — это другой случай, раздел 17.6.

# 11. Работа на станке

Вкладка **«Управление»**.

## 11.1. Элементы

- **поле состояния** вверху — что система делает сейчас: «нет связи»,
  «ожидание», «контроль работы», «защита снята», «АВАРИЯ»;
- **кнопка СТОП ВСЁ** — останавливает обе оси немедленно;
- **карточка «Шпиндель»** — обороты, ток, реле, время работы и полоса
  «вращение — порог взвода защиты»;
- **карточка «Защита от закусывания»** — тумблер защиты, выбор метода и
  уставки;
- **карточки осей X и Y** — джог по стрелкам, поле «ход, мм», кнопка «Обнулить».

## 11.2. Два способа двигать стол

**Джог.** Зажмите кнопку со стрелкой или клавишу на клавиатуре — стол едет,
пока кнопка нажата. Отпустили — стоп. Это повседневный режим.

**Ход.** Впишите в поле «ход, мм» расстояние и нажмите кнопку со стрелкой
направления. Ось разгонится, пройдёт заданный путь и остановится сама.

## 11.3. Стол не должен ехать сам

Система не инициирует движение без команды оператора: ни при включении, ни при
восстановлении связи, ни при сбросе аварии. Если стол поехал сам — это заедающая
кнопка на панели или на клавиатуре: отпустите её.

## 11.4. Обнуление

Кнопка **«Обнулить»** обнуляет счётчик шагов на месте: система продолжает
считать ход от текущего положения как от нуля. Кнопка неактивна, пока ось
едет, — обнуляться на ходу нельзя.

**Обнуление не привязывает стол к станку.** Это не «поехали домой», а просто
смена нуля счёта. Физическое положение стола нигде не запоминается.

## 11.5. Чего нет

Привод в дом и подтверждение домашнего положения сняты. Команды `H` и `HC`
не поддерживаются и отвечают `ERR НЕИЗВЕСТНАЯ КОМАНДА`. Направление хода
задаёт кнопка со стрелкой, которую нажали.

# 12. Концевики

## 12.1. Назначение

Концевик — **аварийный упор**, а не домашнее положение. Ось не обязана
доезжать до него: он страхует от выхода за пределы.

## 12.2. Что происходит при нажатии

1. Останавливается та ось, у которой нажат концевик.
2. Защёлкивается авария 4 «Сработал концевик».
3. Обе оси останавливаются.
4. В журнале появляется строка `#КОНЦЕВИК`.

**Сброс аварии невозможен**, пока выключатель физически нажат. Плата ответит
`ERR КОНЦЕВИК ЕЩЁ НАЖАТ`, кнопка сброса в панели неактивна.

## 12.3. Как отвести ось

Отвод — единственное движение, которое разрешено при нажатом концевике.

1. Отпустите выключатель, если он удерживается нажатым.
2. Ведите ось джогом **в сторону выхода из концевика** — то есть от концевика.

Уводить ось в сторону концевика плата не даст: `ERR ПУТЬ К КОНЦЕВИКУ ЗАКРЫТ`.

## 12.4. Если концевик задели рукой при стоящей оси

Плата не знает, с какой стороны подошёл выключатель. Первый ход после этого
сам задаёт сторону: **куда оператор ведёт ось, там выход**. Если первый ход
уведёт ось дальше в концевик — ход будет отклонён, и придётся вести в другую
сторону.

## 12.5. Подключение

Полная схема с примерами — в разделе 5.4 (вариант по умолчанию) и 5.5 (на
нормально замкнутом контакте). Кратко:

- X-1 — пин **D3**, X-2 — **D4**, Y-1 — **D10**, Y-2 — **D12**;
- выключатели KW1-103-6: общий вывод на **GND**, рабочий контакт на свой пин;
- по умолчанию рабочий контакт — **нормально разомкнутый**, потому что входы
  платы подтянуты к +5 В и нажатие должно гасить пин (настройка 13 = «нажатие
  даёт LOW»);
- **внешние подтягивающие резисторы не нужны** — подтяжка внутрипроцессорная,
  включается прошивкой на всех четырёх входах;
- если выбран вариант с нормально замкнутым контактом (5.5) — обязательно
  поставьте настройку 13 = «нажатие даёт HIGH», иначе ход будет закрыт.

## 12.6. Штатная схема

На новых станках штатные концевики не подключены — пины свободны. Если они
подключены, выберите их как X-1/X-2/Y-1/Y-2 в порядке слева направо при взгляде
со стороны оператора и отключите неиспользуемые в настройках.

# 13. Защита от закусывания фрезы

## 13.1. Принцип

Система следит за оборотами шпинделя и током его привода. Если фреза застряла,
обороты падают, а ток растёт. Оба признака означают закусывание, и стол
останавливается. Реле может дополнительно отключить шпиндель — что именно оно
делает, решает оператор при подключении.

## 13.2. Методы защиты

| Метод | Что проверяет |
|---|---|
| Обороты MIN | обороты упали ниже уставки |
| Обороты MIN + MAX | и падение, и всплеск выше максимума |
| Ток | ток превысил уставку |
| Обороты и ток | и падение оборотов, и рост тока |
| Обороты MIN + Ток | падение оборотов и рост тока |

Выбор метода сам включает защиту. В аварии кнопка защиты и список метода
заблокированы — снять защиту в момент закусывания нельзя.

## 13.3. Взвод и сброс

Защита не срабатывает мгновенно после пуска шпинделя. Пока обороты не достигли
**порога взвода**, система в состоянии «ожидание»: защита есть, но не взведена.

| Параметр | Что делает |
|---|---|
| Время на разгон, мс | сколько ждать разгона шпинделя |
| Порог взвода, об/мин | минимальные обороты, при которых защита взводится |
| Страховка взвода, мс | если за это время порог не взят — защита всё равно взводится |
| Допуск времени, мс | сколько должно длиться нарушение, чтобы сработала авария |

**Страховка важна.** Если порог взвода завышен, шпиндель до него не дотянет,
и защита не взведётся никогда. Страховка через заданное время взводит защиту
в любом случае, а панель пишет «порог завышен» — так вы узнаете, что уставку
надо снизить.

## 13.4. Что делать при аварии

| Авария | Что делать |
|---|---|
| 1 — обороты упали | снять фрезу, поднять обороты, сбросить аварию |
| 2 — обороты выше максимума | проверить датчик и уставку максимума |
| 3 — ток выше уставки | снять фрезу, проверить затупление, возможно снизить уставку |
| 4 — сработал концевик | отвести ось от концевика, раздел 12.3 |
| 5 — пропала связь с панелью | проверить кабель USB, раздел 16 |

Сброс аварии: кнопка **«Сбросить аварию»**. Пока не устранена причина, плата
сама не сбросит и пуск оси не разрешит.

## 13.5. Пуск при висящей аварии

Пока авария не сброшена, стол не поедет. Это осознанное ограничение. Единственное
исключение — **отвод от нажатого концевика**: его пуск разрешён всегда, иначе
отвести ось было бы нечем, и стол остался бы упереться в выключатель навсегда.

# 14. Журнал событий

Журнал внизу главной страницы показывает каждое изменение состояния станка.
Плата объявляет события сама, а не по запросу, поэтому в журнале видно, что
происходило, даже если вас не было у станка.

| Строка | Что означает |
|---|---|
| `#ХОД X НАЧАЛО …` | ход начат |
| `#ХОД X ОКОНЧЕН: цель …, p …` | ход дошёл до цели |
| `#ХОД X ПРЕРВАН: цель …, p …` | ход прерван: стоп, авария или сторож |
| `#КОНЦЕВИК X-1 НАЖАТ: ось ехала` | упёрлись в концевик на ходу |
| `#КОНЦЕВИК X-1 НАЖАТ: ось стояла` | задели рукой на стоящей оси |
| `#КОНЦЕВИК X-1 ОТПУЩЕН` | концевик отпущен |
| `#СТРАХОВКА: путь к концевику закрыт` | ось поехала к концевику и остановлена |
| `#ДЖОГ X ВКЛ, в сторону 0` | начат джог |
| `#СТОП X: команда` | остановка кнопкой |
| `#СТОП ОБЕИХ ОСЕЙ: команда` | сработала кнопка «СТОП ВСЁ» |
| `#ОБНУЛЕНА X: было …, стало 0` | обнулён счётчик шагов |
| `#АВАРИЯ 3 ток выше уставки: …` | сработала авария |
| `#АВАРИЯ СБРОШЕНА` | авария сброшена |
| `#СБРОС ОТКАЗАЛ: концевик ещё нажат` | сброс не прошёл, выключатель нажат |
| `#ПОТЕРЯ СВЯЗИ: 3001 мс без команд` | панель перестала слать команды |
| `#ПОДМЕНА КОНЦЕВИКА X-1 = НАЖАТ` | включена подмена на стенде |

## 14.1. Как читать остановку

Ключевая строка — **`#ХОД … ПРЕРВАН`**. Если в журнале есть она, значит стол
остановился не сам по себе, а было событие. Смотрите, что стоит **перед** этой
строкой: `#КОНЦЕВИК` — концевик, `#АВАРИЯ` — защита, `#СТОП` — кнопка.

Если есть только `#СТОП X: команда` и никакой аварии — остановка произошла по
кнопке панели. Проверьте, не заедает ли кнопка или клавиша.

# 15. Стенд: проверка без станка

Вкладка **«Стенд»** — та же страница управления, но с блоком подмены датчиков
сверху. Двигатели и датчики не нужны: обороты, ток и концевики подменяются.

## 15.1. Что подменяется

| Элемент | Как подменяется |
|---|---|
| Обороты шпинделя | ползунок 0…6000 об/мин |
| Ток привода | ползунок 0…20,0 А |
| Концевики X-1, X-2, Y-1, Y-2 | кнопки-переключатели |

Переключатель **«Эмуляция»** включает подмену. Выключен — плата читает
настоящие датчики.

## 15.2. Правила безопасности стенда

- стенд **изолирован**: он меняет настройки платы только в оперативной памяти,
  в EEPROM не пишет ничего;
- при выходе со вкладки подмена снимается, концевики отпускаются, оси
  гасятся, а настройки возвращаются к рабочим;
- **ползунки по умолчанию на нуле** — при нулевых оборотах защита не взводится,
  поэтому стенд не срабатывает ложно.

## 15.3. Порядок работы

1. Войдите на вкладку «Стенд».
2. Задайте обороты и ток ползунками; концевики отпущены.
3. Включите «Эмуляцию».
4. Запустите ход осей штатными кнопками карточек осей.
5. Плавно поднимайте обороты и ток и смотрите на поведение защиты.
6. Нажимайте концевики и смотрите, как защита останавливает приводы.

## 15.4. Автотесты

Полный прогон протокола, концевиков, защиты, рампы и таймингов — 37 проверок:

```
powershell -ExecutionPolicy Bypass -File bench\jmd2l_test.ps1 -Port COM4 -ShortRunSec 20
```

Текущий результат — **37 из 37**. Моторы не нужны: датчики подменяются.

# 17. Диагностика

## 17.1. Панель не открывается

1. Откройте окно, которое осталось от запуска. Есть строка об ошибке — её текст
   и есть причина.
2. Проверьте, не занял ли порт 8080 другой процесс.
3. Запустите вручную из папки программы:

```
node\node.exe server\server.js
```

## 17.2. Плата не отвечает

| Симптом | Причина |
|---|---|
| «COM-портов не найдено» | плата не подключена или не установлен драйвер CH340 |
| порт есть, «нет ответа на ?» | плата занята другой программой |
| баннера нет вовсе | плата в загрузчике из-за RTS — переподключите питание |
| порт открывается и сразу отваливается | неверная скорость или повреждён кабель |

## 17.3. Ось не двигается

По журналу на главной странице найдите причину:

| Строка в журнале | Что делать |
|---|---|
| `ERR СКОРОСТЬ НЕ ЗАДАНА` | скорость на ползунке равна нулю |
| `ERR ШПИНДЕЛЬ НЕ ВРАЩАЕТСЯ` | включите шпиндель либо разрешите ход при стоящем |
| `ERR ПУТЬ К КОНЦЕВИКУ ЗАКРЫТ` | ведите ось в другую сторону, раздел 12.3 |
| `ERR СБРОСЬ АВАРИЮ` | сначала сбросьте аварию |
| `ERR ОСЬ ЗАНЯТА` | ось уже едет — дождитесь конца хода |
| `ERR КОНЦЕВИК ЕЩЁ НАЖАТ` | выключатель физически нажат |
| авария висит | сбросьте её кнопкой, устранив причину |

## 17.4. Стол едет не туда

| Признак | Причина |
|---|---|
| едет медленнее заданного в разы | неверно выставлены шаги на миллиметр |
| едет в обратную сторону | не инвертировано направление оси, Пусконаладка шаг 5 |
| уезжает и не останавливается | потеряна связь с платой, проверьте журнал |
| в журнале `hz` 9913, фактически 4100–4600 шаг/с | известная невыясненная особенность, раздел 17.6 |

## 17.5. Защита срабатывает сама

| Признак | Причина |
|---|---|
| авария 1 при обычной работе | порог взвода или минимум оборотов завышен |
| авария 3 при нормальном токе | не откалиброван ноль датчика тока |
| защита не взводится и пишет «порог завышен» | снизьте порог взвода |
| авария 5 через несколько минут | оторвался USB-кабель или компьютер уснул |

> Калибровка нуля датчика тока: выключите шпиндель, дождитесь нулевых
> показаний и нажмите «Калибровка тока». Замер идёт полсекунды.

## 17.6. Ось едет вдвое медленнее заданной

Отдельно известный случай: в журнале плата пишет `hz` = 9913 шаг/с, а стол
фактически едет 4100–4600 шаг/с — примерно вдвое медленнее. При этом ход
сходится правильно, ось не теряет шаги: верно всё, кроме скорости.

Причина **не установлена**. Это не ошибка пересчёта шагов (сходится ход) и не
предел частоты (9913 далеко до 20000, раздел 10.4). На стенде без моторов не
воспроизводилось, на собранном станке не проверялось.

Что попробовать:

1. Снимите нагрузку: отключите стол от направляющих и выполните ход на 200 мм.
2. Уменьшите скорость вдвое. Если отношение осталось прежним, дело не в рампе
   и не в настройке — сообщите разработчику.
3. Вспомните, какая прошивка залита: смена прошивки может изменить поведение.

# Приложение В. Команды протокола

Связь: ASCII, строки, `\n`, 115200 бод. Ответ — `OK`, `PONG` или `ERR <текст>`.
Нужны при диагностике и при доработке.

| Команда | Действие |
|---|---|
| `?` | запрос состояния, ответ — строка JSON |
| `!` | баннер и версия |
| `PING` | проверка связи, ответ `PONG` |
| `V <ось> <шаг/с>` | задать скорость шагами |
| `R <ось> <об/мин>` | задать скорость оборотами |
| `D <ось> <0\|1>` | направление, только при остановке |
| `G <ось>` | пуск, джог |
| `S <ось>` | стоп оси |
| `X` | стоп обеих осей |
| `N <ось> <шагов>` | ход на число шагов с рампой, минус — другая сторона |
| `Z <ось>` | обнулить счётчик шагов на месте |
| `A <ось> <0\|1>` | включение драйвера оси |
| `AR <ось> <шаг/с²>` | ускорение |
| `T` | все настройки |
| `T <i> <значение>` | изменить настройку в оперативной памяти |
| `TS` | сохранить настройки в память платы |
| `TD` | вернуть умолчания |
| `K` | калибровка нуля тока, замер 0,5 с |
| `C` | сбросить счётчик тахометра |
| `W` | диагностика времени, ответ — JSON |
| `W0` | сбросить счётчики диагностики |
| `L <0..3> <0\|1>` | подмена состояния концевика, проверка |
| `RP <об/мин>` | подмена оборотов, проверка |
| `CU <0.1 А>` | подмена тока, проверка |
| `RL <0\|1>` | реле вручную, проверка |

Подмены `RP`, `CU`, `L` постоянны до явной отмены: `RP -1`, `CU -1`,
`L <i> -1`.

Оси нумеруются: 1 — X, 2 — Y. Концевики в команде `L`: 0 — X-1, 1 — X-2,
2 — Y-1, 3 — Y-2.

Сняты и больше не работают: `H <ось>` (привод в дом), `HC <ось>`
(подтверждение домашнего положения). Отвечают `ERR НЕИЗВЕСТНАЯ КОМАНДА`.

| `ШПИНДЕЛЬ НЕ ВРАЩАЕТСЯ` | включить шпиндель |
| `ПУТЬ К КОНЦЕВИКУ ЗАКРЫТ` | вести ось в другую сторону |
| `КОНЦЕВИК ЕЩЁ НАЖАТ` | отпустить выключатель, потом сбросить аварию |
| `СБРОСЬ АВАРИЮ` | нажать сброс аварии |
| `СНАЧАЛА СТОП` | остановить ось перед этой командой |
| `ОСЬ ЗАНЯТА` | дождаться конца хода |
| `НЕТ ОСИ` | номер оси вне 1…2 |
| `ТОК ПОДМЕНЁН` | снять подмену `CU` |
| `НЕИЗВЕСТНАЯ КОМАНДА` | опечатка или снятая команда |

## В.2. Коды аварий

| Код | Значение |
|---|---|
| 0 | аварии нет |
| 1 | обороты шпинделя упали ниже уставки |
| 2 | обороты выше максимума |
| 3 | ток выше уставки — закусывание |
| 4 | сработал концевик |
| 5 | пропала связь с панелью |
